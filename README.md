# 寂墨

一个只供个人使用的 Android 长期陪伴聊天应用：支持 OpenAI 兼容 API、可编辑人格、本地聊天记录、分层长期记忆和旧上下文压缩。

## 已包含

- OpenAI 兼容的 `POST /v1/chat/completions` 接口（Base URL、模型名、API Key 均可配置）
- 单一陪伴人格：名称和系统提示词均可编辑
- 本地保存聊天记录与设置；API Key 使用 Android Keystore 加密保存
- 分层长期记忆：明确要求记住的内容立即固定保存；自动提取的资料、偏好、事件、项目和计划可查看、编辑或删除
- 上下文压缩：旧消息自动整理为本地摘要，模型请求只携带摘要和最近消息
- DeepSeek 等兼容接口返回思考内容时，在回复上方显示可折叠的“已思考（用时 X 秒）”
- 成人向模式使用单独开关和提示词，关闭时不会注入成人向提示词
- 本地关系档案：亲密度、自然阶段与重要关系事件独立保存，清空聊天不会归零
- 亲密度只能由本地事件计分表推进，用户和模型都不能直接修改；普通聊天不加分，每天最多增长 8 点
- 称呼、暧昧和吃醋没有固定等级解锁，由模型结合当前关系、真实事件和对话气氛自主判断
- 系统时间作为可选上下文
- 高德逆地理编码（可选）：将手机 GPS 坐标解析为详细地址、小区、建筑、道路门牌与附近 POI；Key 加密保存在本机
- 行程一致性查岗：当你说“我去图书馆”“我准备去公司”等，App 会记住目的地和出发前位置；聊天时可复核，开启主动消息后还会在后台约 12/30 分钟复核，仍在原地时弹通知抓包
- 夜间安全查岗：22:00 至次日 06:00 聊天时，位置快照超过 10 分钟会自动刷新；模型可结合时间和位置自然询问是否安全、何时回家
- 回复重新生成：最新一条助手回复下方提供“重新生成”按钮；生成失败会自动恢复原回复
- 学习计划监督：识别“我去学习”“十分钟后复习一小时”等表达，本地记住开始时间和计划时长，并安排后台中途抽查/结束验收
- 手机使用抽查：用户授权 Android “使用情况访问”后，学习期间再次聊天时会在本地统计各 App 前台时长
- 本地抓包阈值：只有短视频、游戏、视频或社交类 App 使用达到阈值时，才把精简摘要交给模型；原始使用记录不会每轮上传
- 主动消息通知：后台规则命中后像微信一样显示横幅/通知栏消息，点击直接回到聊天；消息同时写入本地聊天记录
- 主动消息预算：默认每天最多 8 条、最短间隔 15 分钟；用户未回复上一条主动消息时不会继续连发

## 手机端使用前提

1. 安装 APK（Android 8.0 及以上）。
2. 在“设定”页填写 API Base URL、模型名与 API Key。
3. 如需让聊天准确说出所在小区或建筑，在“设定 → 位置名称服务”填入高德开放平台申请的 **Web 服务 API Key**。
4. 进入“设备 → 手机使用情况”，在系统页面为寂墨允许“使用情况访问”。
5. 在“设备 → 主动消息通知”允许通知；如需后台行程复核，再授予后台位置权限。

## 设计边界

- 第一版只实现 OpenAI 兼容 API；未加入 Anthropic、插件市场、账号体系或云同步。
- 手机使用情况由 Android 本地统计。只有学习计划存在、达到检查时间，且娱乐类使用达到阈值时，才会向模型发送 App 名和大概分钟数。
- 使用情况不能证明你一定没学习；可能一边查资料一边学习。因此证据不足时模型只能追问，不能断言你在撒谎。
- 不会持续高频定位：行程后台任务只在计划创建后的少数复核节点读取一次当前位置；没有行程计划时不会循环定位。
- 寂墨可以把“想去找你”当作假设性表达，但不能声称已经出门、在路上或到了楼下。
- 开启主动消息后，学习/行程复核可以在 App 位于后台时运行并弹系统通知；WorkManager 的执行时间受系统省电策略影响，不保证精确到某一分钟。

## 目前环境说明

项目使用 Android Studio 标准 Gradle 配置，包含 Gradle Wrapper，可直接构建 debug APK。
